# Simple Interest Calculator

This project is a simple interest calculator that calculates interest based on the principal amount, rate of interest, and time period.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

## Features

* Accepts principal amount
* Accepts interest rate
* Accepts time period
* Calculates simple interest
* Easy to use and understand

## Example

If:

* Principal = 1000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (1000 × 5 × 2) / 100 = 100**

## Usage

Run the program and enter the required values when prompted.
